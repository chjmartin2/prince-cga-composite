game-accurate two-sample right-facing transform. Its functional change is the
correct frame map: image 51 now has all four runtime cases, image 64 begins the
run-turn sequence, and images 75..76 complete it.

The unselected baseline contains 183 unselected images plus the table header,
all byte-identical to the verified VGA/Exhaustive/No-Dither phase-0 KID.DAT.
No all-phase objective is used anywhere in V13.
